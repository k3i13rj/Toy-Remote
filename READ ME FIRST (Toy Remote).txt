TOY REMOTE FOR ANDROID - QUICK START (version 0.1, first test version)
====================================================================

Toy Remote lets people you approve control your Love Spouse toy from
Telegram, using buttons. Only YOUR phone needs this app. The other
person just uses Telegram, on any phone (Android or iPhone).

This is a separate app from Tip Bridge. Installing it doesn't change
Tip Bridge. Don't run both at the same time: press STOP in one before
pressing START in the other.

WHAT YOU NEED
- Your Android phone with Telegram installed
- Your Love Spouse toy (charged and switched on)

STEP 1 - Install the app
  Same as Tip Bridge: open the download link on your PHONE, tap
  "ToyRemote.apk", then Install and Open. (If Play Protect warns you,
  choose "More details" then "Install anyway".)

STEP 2 - Make your bot (one time only)
  1. In Telegram, search for @BotFather (it has a blue check mark)
     and open it.
  2. Send: /newbot
  3. Give it any name, e.g. My Toy Remote.
  4. Give it a username ending in "bot", e.g. mytoyremote2026_bot.
  5. BotFather replies with a code that looks like
     123456789:AAH4k... Press and hold it to copy.
  Keep this code SECRET - anyone with it can take over your bot.

STEP 3 - Start the app
  1. Open Toy Remote and paste the code into the first box.
  2. Optional: type the name people should see on their remote,
     e.g. a stage name. They'll see "Connected to [name]". If empty,
     your Telegram first name is used.
  3. "Use the toy's built-in modes" is ticked: Mode 1-9 are the same
     as in the Love Spouse app, each with its own fixed strength.
     The "Strongest" limit doesn't apply to them. If a mode doesn't
     behave like in the Love Spouse app, untick this to use patterns
     made by Toy Remote instead (those follow the "Strongest" limit,
     which is Level 3, full strength, unless you lower it).
  4. Press START. Allow the Bluetooth ("Nearby devices") and
     notification permissions if asked.
  5. Telegram should turn green: "Connected as @yourbot".
  6. Press "Test toy: buzz for 3 seconds". The toy should buzz.

STEP 4 - Link your own Telegram
  1. In Telegram, open your new bot (search its username) and press
     Start, or send it any message.
  2. In Toy Remote, section 2 shows "Request: your name". Tap
     "This is me".
  3. Press "Test Telegram: send me a test message". Telegram gets a
     message with a "Test buzz" button. Tap it. If the toy buzzes,
     everything works.

STEP 5 - Let the other person in
  1. Send them your bot's username (e.g. @mytoyremote2026_bot).
  2. They open it in Telegram and press Start.
  3. Their request appears in section 2. Tap Allow.
  4. They get a message with the buttons: the 9 modes (named as in
     the Love Spouse app: Heartbeat, Wave, Leap, Entwine, Climax,
     Sea wave, Dance, Surfing, Cha-cha),
     30s / 60s / Until changed, and Stop. (Low / Med / High only appear
     if you untick "Use the toy's built-in modes".)
  5. They're asked once which time zone they're in, so times on their
     remote show in their own local time. They can send /timezone
     to change it.
  Nobody can control the toy unless you tap Allow. You can Remove
  anyone at any time, and their buttons stop working straight away.

HOW THE BUTTONS WORK (for the other person)
  - A mode button starts that mode.
  - Low / Med / High (only with built-in modes switched off): if
    something is running, it changes the strength. If nothing is
    running, it starts a steady buzz.
  - "Until changed" (the default) keeps a mode going until the next
    tap. 30s / 60s make each tap a timed burst instead.
  - For safety, the toy stops by itself after 30 minutes with no taps.
  - Stop stops the toy. Typing "stop" to the bot also works.

WHILE USING IT
  - Keep the phone plugged in, this app open, and the phone close to
    the toy.
  - EMERGENCY STOP halts the toy instantly.
  - Pressing STOP switches the remote off. The other person's buttons
    show "switched off" until you press START again.
  - Taps made while the app was off are ignored, so nothing starts
    by surprise when you turn it back on.

IF THE PHONE CLOSES THE APP BY ITSELF
  Press "Open battery settings" and allow Toy Remote to run without
  limits. On some phones also allow "Auto-start" or "Background
  activity", and lock the app in the recent-apps screen.

IF SOMETHING'S WRONG
  - "bot code is wrong": copy the code from @BotFather again.
  - "bot in use elsewhere": this bot is running in another app or on
    another phone. Close it there.
  - Telegram is green but the toy doesn't react: press "Test toy". If
    that doesn't buzz either, move the phone closer and check the toy
    is on.

NOTE ON THE 9 MODES
  With "Use the toy's built-in modes" ticked (the default), Mode 1-9
  send the same commands as the Love Spouse app. Please check each one
  feels the same as in the Love Spouse app, and that Stop stops the
  toy. If any mode is wrong (for example Mode 1 does nothing), untick
  the setting to use Toy Remote's own patterns instead.
